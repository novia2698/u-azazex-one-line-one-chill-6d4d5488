One sentence of horror, built to land in a single breath: a coroner's contradiction, an autopsy photo that disagrees with the official story, and a date stamp that should not exist yet. The program writes that one line to `entry.txt` for the make.fun judge to compare head to head against the other entries.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set). The line is 117 characters, one sentence, no trailing newline.

## The line

> The coroner swore my father died smiling, but the autopsy photo shows him screaming — and its date stamp is tomorrow.

Why this line: it is a complete horror story in one sentence (a dead man, a lying official record, a photograph that proves the lie), it frightens by what it withholds (who took the photo, whose tomorrow it is), it is vivid and concrete (coroner, autopsy photo, date stamp), it avoids the tired mirror, doll and basement images, and its last word — tomorrow — lands the blow.
